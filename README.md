- **Payments:** Stripe and PayPal integrations.
- **AI:** OpenAI API integration for SQE2 written-answer reviews, using assessment facts and marking criteria as context for feedback.
- **Validation:** Regression tests and live submission-to-feedback checks for scoring and report consistency, including equal weighting of assessment categories.
